# Changelog

## 0.2.0

- New `claudeSoundNotifier.repeat` setting to play each sound several times per event.
- Uninstalling the extension now removes its hooks from `~/.claude/settings.json` and deletes its data folder.
- Added an extension icon.
- Removed the unrelated "Notebooks" Marketplace category.

## 0.1.0

- Initial release: sounds for approval prompts, finished responses and idle prompts, a workspace-aware event router, a status bar mute toggle, and hook install/uninstall commands.
